# Profile kit

Drafts for the places recruiters meet you before they meet this site:
LinkedIn, your GitHub profile, your résumé, and the posts that announce your
work. Everything is written from verified facts (see `PLACEHOLDERS.md`).
Anything only you can supply is a slot in square brackets, like
`[team size]`. Fill the slots, delete the ones you cannot fill truthfully,
and make the wording sound like you.

| File | What it is | Where it goes |
| --- | --- | --- |
| `linkedin.md` | Headline, About, Featured, the Clyra entry, skills | linkedin.com/in/sahilshityalkar |
| `github-profile-readme.md` | A profile README | a public repo named `sahilshityalkar` (same as your username) |
| `resume-bullets.md` | Bullets for the résumé PDF, in the site's words | `public/resume.pdf` |
| `launch-posts.md` | Short posts announcing the portfolio and each note | LinkedIn, X |

Keep the same title, stack words and project names everywhere: recruiters
cross-check, and consistency reads as credibility.
